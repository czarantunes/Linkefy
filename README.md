## SEO técnico

Cada página deve possuir:

- um único `H1`;
- hierarquia correta de `H2` e `H3`;
- `title` exclusivo;
- `meta description`;
- canonical;
- Open Graph;
- Twitter Cards;
- alt text adequado;
- URLs limpas e amigáveis.

Também devem existir:

```text
robots.txt
sitemap.xml
```

Schemas recomendados:

- `Organization`;
- `ProfessionalService`;
- `WebSite`;
- `Service`;
- `BreadcrumbList`, quando aplicável.

Nunca incluir dados falsos ou não comprovados.
